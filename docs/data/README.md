# Datos operativos PAWSI AI (reales)

Fuente: campaña FuCoLla / Convenio UCASAL — **La Caldera**, fecha **28/05/2026**.

Archivo: `base-datos-pawsi-la-caldera-2026-05-28.csv`

Columnas: N°, Fecha, Municipio, Nombre y Apellido, Tipo Mascota, Nombre Mascota, Aporte Insumos, Observaciones, Entidad Gestora.

La columna `Aporte Insumos` registra los aportes de la campaña: gastos de medicamentos y descartables de las cirugías. Ese monto no es para el municipio ni para la universidad. Las intervenciones las realizan estudiantes del último año de la carrera de Medicina de la universidad (Convenio UCASAL), en modalidad de prácticas profesionales, articuladas con FuCoLla y La Caldera.

**Privacidad:** se omitió la columna `N° de Teléfono` en el repositorio público. El dataset original con teléfonos queda solo en custodia de FuCoLla.

Resumen derivado del CSV: 61 filas, 28 perros, 31 gatos, 2 filas sin mascota, aportes de medicamentos y descartables $766.000, entidad gestora Convenio UCASAL. La homepage importa este archivo en el build.
